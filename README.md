# Dr. Sadaqat ur Rehman — Academic Portfolio

A responsive GitHub Pages academic portfolio built from my CV, focused on Artificial Intelligence, Deep Learning, Computer Vision, AI in Healthcare and AI in Education.

## Live website

After publishing with GitHub Pages, add the URL here:

`https://YOUR-USERNAME.github.io/`

## Deploy on GitHub Pages

1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload these files to the root of the repository:
   - `index.html`
   - `Sadaqat_Rehman_CV.pdf`
   - `README.md`
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Your site will be available at `https://YOUR-USERNAME.github.io/`.

## Customise

The website is intentionally dependency-free: all HTML, CSS and JavaScript are inside `index.html`.

Useful edits:

- Replace the initials avatar (`SR`) with a photograph later if desired.
- Add LinkedIn, ORCID, GitHub or institutional profile links.
- Update the publication cards when new papers are published.
- Keep `Sadaqat_Rehman_CV.pdf` updated so the **Download full CV** button always opens the latest version.
